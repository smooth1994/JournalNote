# 拾光手账 · UI 设计方案

> **把时光，一页一页捡起来**
> 版本 v1.0 · 2026-08-12 · 平台：iOS（Swift / UIKit & Storyboard）

---

## 1. 产品定位与设计理念

| 维度 | 说明 |
|---|---|
| 产品名 | 拾光手账（Shiguang Journal） |
| 定位 | 治愈系复古手账 App —— 沉浸式记录生活片段 |
| 目标用户 | 18–35 岁，喜欢手账文化、追求仪式感与情绪价值的记录者 |
| 设计隐喻 | 「一本被岁月温柔对待的旧手账」 |

**三条设计原则：**

1. **治愈 Healing** —— 低饱和暖色调、大留白、柔和圆角、慢节奏动效；拒绝红点焦虑。
2. **复古 Retro** —— 牛皮纸纹理、衬线宋体、手写批注、火漆印章、和纸胶带等实体手账元素数字化。
3. **沉浸 Immersive** —— 书写页零干扰（隐藏导航）、信纸横线、环境音、拟物翻页。

## 3. 字体系统

| 角色 | 字体 | 字重 | 规格 |
|---|---|---|---|
| 页面大标题 | 宋体（Songti SC / Noto Serif SC） | Bold | 34px / 字距 4px |
| 卡片标题 | 宋体 | Semibold | 22px |
| 正文 | 宋体 | Regular | 16px / 行高 1.75 |
| 辅助说明 | 宋体 | Regular | 14px |
| 情感点缀 | 手写体（马善政 / 行楷） | — | 批注、空状态、落款 |
| 时间戳 | 等宽体（JetBrains Mono） | — | 12–14px / 字距 1px |

字阶：`12 / 14 / 16 / 18 / 22 / 28 / 34`，支持 iOS Dynamic Type 至 200%。

## 4. 间距 · 圆角 · 阴影 · 动效

- **间距**：4pt 基准 —— `4 / 8 / 12 / 16 / 24 / 32 / 48`
- **圆角**：小件 8 · 卡片 14 · 面板 20 · 胶囊 999
- **阴影**（暖棕系，忌用纯黑投影）：
  - `shadow-card`: `0 2px 8px rgba(58,49,40,.06), 0 8px 24px rgba(58,49,40,.08)`
  - `shadow-lift`: `0 4px 12px rgba(58,49,40,.10), 0 12px 32px rgba(58,49,40,.12)`
- **动效**：统一缓动 `cubic-bezier(.22,1,.36,1)`，常规 200–350ms；翻页转场 500ms + 纸张摩擦音效（可关闭）；开启 Reduce Motion 自动降级为淡入淡出。

## 5. 核心组件

| 组件 | 要点 |
|---|---|
| **按钮 Button** | 胶囊圆角 + 2px 字距；主按钮焦糖底 + 30% 焦糖投影；变体：Primary / Ghost / Soft；最小高度 44pt |
| **心情选择器 Mood** | 52pt 圆形 Emoji，选中放大 1.12× + 焦糖描边；😊开心 🌿平静 🌧思绪 🌙想念 🍂感怀 |
| **输入框 Input** | 1.5px `paper-300` 描边；聚焦焦糖描边 + 4px 12% 外发光 |
| **手账卡片 Note Card** | 顶部 4px 心情色条；和纸胶带装饰；悬停倾斜 -0.4° |
| **标签 Tag** | 18% 透明度素材色底 + 加深文字（保证 AA 对比度） |
| **印章 Seal** | 砖红篆刻风，用于连续记录 / 周年纪念等成就时刻 |
| **时间轴 Timeline** | 心情色圆点 + 1.5px 纸色竖线串联 |

## 6. 信息架构与核心页面

**底部 Tab（4 项）**：📖 时光轴 · 🗓 日历 · ✏️ 书写（中央主行动）· 🕯 我的

1. **首页 · 时光轴** —— 倒序时间流，心情色点 + 手账卡片，月度拾光计数。
2. **沉浸式书写** —— 信纸横线背景、零干扰、手写体称呼开场；底部工具条：笔/图/贴纸/音乐/标签；保存时拟物翻页。
3. **日历回顾** —— 有记录的日子以焦糖底色「点亮」+ 砖红印记；月统计与心情占比。
4. **手账详情** —— 照片头图 + 正文 + 标签，右下角火漆印章落款。
5. **我的（🕯）** —— 心情年轮（年度心情热力图）、连续记录印章墙、夜灯模式开关、数据导出（PDF 手账册）。

---

## 7. 无障碍与适配

- 全文颜色对比度满足 WCAG AA（正文 ≥ 4.5:1）
- 触控目标 ≥ 44×44pt
- 支持 Dynamic Type 200%、VoiceOver 语义标签、Reduce Motion 降级
- 适配 iPhone SE(375pt) → Pro Max(430pt) 弹性布局，安全区适配

---

## 8. 开发交付建议（iOS）

- 色彩/字体/间距以 `UIColor` / `UIFont` 扩展 + Design Token 常量落地（可直接映射上表 Hex）
- 纸感纹理建议用轻量 tiling 图片（≤ 50KB WebP）叠加于 `paper` 底色
- 翻页转场可用 `UIPageViewController` 或自定义 `UIViewControllerTransitioning`
- 手写体需确认商用授权（建议：站酷/思源衍生或购买授权字体）
