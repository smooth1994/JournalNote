# 拾光手账 V2.0 迭代 UI 设计规范 —— 「计划」模块

> 目标：从「记录过去」升级为「计划当下」。新增「计划」Tab，承载每日任务与重复任务，建立"昨日封存 / 今日行动 / 明日预览"的时间轴心智。

---

## 1. 迭代范围

| 功能点 | 优先级 | 说明 |
|---|---|---|
| 新增「计划」TabBar | P0 | TabBar **维持 4 个**：时光轴 / 日历 / **计划** / 我的（徽章已下沉至「我的」页内入口，不再独立成 Tab） |
| 任务类型 | P0 | 单次（仅今天）、每天、工作日（周一~五）、每周末、自定义周几 |
| 按天滑动浏览 | P0 | 默认显示今日；左右滑查看昨天 / 明天（滑动边界：第一天 ~ +30 天） |
| 过期只读 | P0 | 昨天及更早：不可编辑、不可补勾；过期未勾任务红底红字标红 |
| 未来不可勾选 | P0 | 明天及未来：勾选框禁用（🔒），仅可预览与新增 |
| 全部完成庆祝 | P1 | 当日任务全部完成时的印章/进度环动效 |

---

## 2. 视觉规则

延续 V1.0 Tokens（纸 `#FBF7EF` / 焦糖 `#B07B4E` / 鼠尾草绿 `#93A084` / 金箔 `#D4A056`），新增：

| Token | Hex | 用途 |
|---|---|---|
| 过期红 | `#C24A34` | 过期未勾任务文字/勾选框 |
| 过期底 | `#FBEDE8` | 过期未勾任务卡片背景 |
| 锁定灰 | `#D8CFBE` / `#F1EDE4` | 未来日期禁用态 |

**Tab 图标**：🌱 嫩芽（计划）；当日有未完成任务时图标右上角显示小圆点。

---

## 3. 页面结构（三态同一布局）

```
导航（大标题「计划」+ 当天日期）
├─ 日期翻页器  [‹] 今天 09.03 周四 · N/M 已完成 [›]
├─ 进度环卡（今日态）conic-gradient，中心 N/M
├─ 分组任务列表：每日循环 / 工作日循环 / （今天|当天）新增
│    每项：勾选框 + 标题 + 重复说明 + 类型标签 + 连续天数🔥
├─ 封存横幅（昨日态）/ 锁定横幅（未来态）
└─ CTA「＋ 新增当日任务」（今日/未来态显示，昨日态隐藏）
```

### 3.1 任务卡状态

| 状态 | 样式 |
|---|---|
| 未完成（今日） | 白卡、焦糖描边空勾选框 |
| 已完成 | 绿色实心 ✓ + 标题删除线降灰 |
| 过期未勾（昨天及更早） | 红底 `#FBEDE8`、红字、红 ✕ 勾选框、标签「未完成」；整卡 opacity .55、只读 |
| 未来（明天及更早） | 勾选框 🔒 灰底禁用；整卡 opacity .55 |

### 3.2 编辑规则（核心需求 4 / 5）

| 日期 | 勾选 | 编辑/删除 | 新增 |
|---|---|---|---|
| 今天 | ✅ | ✅ | ✅ |
| 昨天及更早 | ❌（✕ 展示） | ❌ 全只读 | ❌ |
| 明天及未来 | ❌（🔒 展示） | ✅（仅标题/重复规则） | ✅ |

- 过 0 点自动回到「今天」；昨日视图首次进入时未完成卡有"渐变标红 + 已封存"提示。
- 重复任务长按 → 修改 / 暂停 / 删除，作用于「之后所有天」。

---

## 4. 新建任务 Sheet

- 字段：标题 → 重复规则（仅今天/每天/工作日/每周末/自定义…）→ 自定义周几胶囊（多选）→ 归属日期 → 提醒（本地通知）。
- 在滑到的某一天新建时，归属日期默认为该天。

## 5. 动效

| 场景 | 动效 |
|---|---|
| 勾选完成 | ✓ 200ms 弹出 + 卡片回弹；全部完成触发金箔进度环 + 「今日计划 · 已完成」印章 |
| 天切换 | 卡片横向位移 280ms + 翻页器数字滚动；未来页勾选框逐个"落锁" |
| 过期标红 | 0 点后首入昨日视图：白→红底渐变 500ms |

## 6. 数据与开发

- 模型：`Task { id, title, rule, weekdays[], anchorDate, reminder }` + `TaskInstance { date, done, doneAt }`；实例懒生成。
- 只读判断基于本地日历日 0 点，服务端不提供补勾。
- 联动：完成数据计入徽章体系（如「计划达人 · 连续完成 7 天」）；「睡前写手账」完成可一键跳转书写页。
- 无障碍：锁定框朗读「未来任务，到达当天可完成」；过期朗读「已过期，不可编辑」。
