拾光手账 V2.0 · 「计划」模块

核心目标：把手账从「记录过去」升级为「计划当下」。新增独立「计划」Tab，支持每日任务与重复任务（每天 / 工作日 / 每周末 / 自定义周几）；页面以「天」为轴横向滑动，昨日不可改、明日不可勾、过期标红。视觉延续 V1.0 纸感复古设计语言。

一、信息架构：TabBar 维持 4 个（徽章并入「我的」）

新增「计划」Tab 排在「日历」之后；徽章不再独立成 Tab，已下沉为「我的」页面内的入口。

交互细则

  • 仅今天：单次任务，只出现在归属日期当天
  • 每天：未来每一天自动生成实例
  • 工作日：周一～周五；每周末：周六、周日
  • 自定义…：展开周几胶囊多选（可任意组合）
  • 重复任务长按 → 修改 / 暂停 / 删除（作用于「之后所有天」）
  • 空状态插画：一张空页 + 蜡烛，文案「这一页还很安静，写点什么吧」

四、任务状态与编辑规则总表（需求 3 / 4 / 5 落地）

日期状态勾选框过期未勾编辑/删除新增
今天（默认屏）可勾选 ✓—可编辑允许
昨天及更早（封存）✕ 不可操作红底红字标红全部只读 🔒不允许
明天及未来🔒 不可勾选—可编辑（仅重复规则/标题）允许

滑动边界：最早可滑到使用 App 的第一天；最远可滑到 +30 天。翻过 0 点自动回到「今天」。

五、动效要点

勾选完成

  • 打勾 200ms scale 弹出 → 卡片轻压回弹 → 纸感「嗒」音（可选）
  • 全部完成时：顶部进度环点亮金箔描边 + 印章动画「今日计划 · 已完成」

天切换（滑动）

  • 整页卡片横向位移动画 280ms，日期翻页器数字滚动
  • 切到昨日：卡片带「盖章封存」微动效；切到未来：勾选框逐个「落锁」

过期标红

  • 过 0 点后首次进入昨日视图：未完成卡从白渐变至红底 500ms，提示「已封存」

六、数据与开发要点

项说明
数据模型`Task { id, title, rule: once|daily|weekday|weekend|custom(weekdays[]), anchorDate, reminder }` + `TaskInstance { date, done, doneAt }`，实例懒生成、只落库被操作过的天
只读策略客户端按本地日期 0 点冻结；补勾入口不做（与 V1.1 打卡补签区分：计划是承诺，不补）
联动完成「睡前写手账」可一键跳转书写页；完成数据计入徽章（如「计划达人 · 连续完成 7 天」）
无障碍锁定框朗读「未来任务，到达当天可完成」；过期朗读「已过期，不可编辑」
