# 拾光手账 V1.1 迭代 UI 设计规范

> 目标：把「记录」变成「每日仪式」，用打卡与徽章体系强化长期留存。

---

## 4. 关键组件

### 4.1 打卡按钮
- 未打卡：焦糖主按钮，文案「✍️ 记下此刻 · 完成打卡」
- 已打卡：绿色填充，文案「🔥 今日已打卡 · 连续 N 天」

### 4.2 日历单元格状态
- 普通 / `has` 有记录 / `today` 今日 / `checked` 已打卡（绿点） / `locked` 未来日期（浅灰不可点）

### 4.3 徽章卡片
- 尺寸：72pt 圆形
- 锁定态：`grayscale(100%)` + `opacity: .55` + 右下角小锁
- 点亮态：金箔描边 2-3px + 暖金投影 + 徽章外圈旋转高光

### 4.4 徽章详情
- 大徽章 110pt + 进度条 + 获取条件 + 分享按钮
- 解锁时从底部弹出 Sheet

---

## 5. 动效要点

| 场景 | 动效 |
|---|---|
| 打卡成功 | 印章盖下 300ms → 火焰 scale 1.2 → 连续天数 +1 |
| 徽章解锁 | 灰度淡出 500ms + 金边 0°→360° 生长 + Sheet 弹出 |
| 补签 | 日期格橙色标记 + Toast「补签成功」|

---

## 6. 数据与开发要点

- 打卡与日记一一对应；「快速打卡」生成一条短日记。
- 补签每月限 2 次，带 `is_makeup=true` 标记。
- 徽章配置服务端化：`badge_id / series / unlock_condition / progress`。
- 未来信箱使用本地通知 + 本地加密存储。
- 无障碍：徽章朗读「未解锁，连续打卡 7 天可点亮」；进度条读百分比。
