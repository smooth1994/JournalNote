01

迭代范围与优先级

在现有「时光轴 / 日历 / 我的」三 tab 基础上，V1.1 聚焦「养成感」与「成就反馈」：把单次记录行为变成可感知的每日仪式，用徽章体系强化长期留存。

模块功能点优先级价值
日历打卡今日打卡按钮、连续打卡天数、月度打卡视图、补签机制P0将记录转化为每日仪式，提升打开频次
徽章系统徽章中心、系列分类、锁定/点亮态、进度、详情页P0游戏化成就反馈，增强长期留存
每日灵感首页顶部每日写作提示，可一键引用P1降低「不知道写什么」的启动阻力
月度手账报告每月生成一页可视化报告卡，可分享/导出P1强化回顾价值与分享传播
未来信箱写给未来自己的信，设定日期后封存并到期提醒P2情感化功能，提升产品记忆点
02

设计原则与 Token 延续

延续 V1.0 的治愈复古基调，新增「养成感」视觉线索：火焰（连续）、金属锁（未解锁）、金箔描边（已点亮）。不引入高饱和插画，保持纸感与克制。

色彩
主色焦糖 `#B07B4E` · 成功绿 `#93A084` · 砖红 `#B5533C` · 新增金箔 `#D4A056` 用于徽章高光
材质
纸纹底、火漆印章、和纸胶带；徽章锁定态用灰度 + 哑光，点亮态用金箔描边 + 暖光投影
动效
打卡成功：印章落下 300ms + 火焰跃起；徽章解锁：灰度转彩色 500ms + 金边生长动画
03

日历打卡模块

在原有日历页增加「今日打卡」主行动点，并把「有记录」与「已打卡」区分开：有记录自动打卡；无记录时可点击打卡写一句话。连续打卡用火焰与 streak 数字强化。

新增/更新组件规范

组件规范
打卡按钮未打卡：焦糖主按钮，文案「记下此刻 · 完成打卡」；已打卡：绿色填充，文案「🔥 今日已打卡 · 连续 N 天」
日历单元格普通 / 有记录 has / 今日 today / 已打卡 checked（绿色小点）/ 锁定未来 locked（浅灰）
徽章卡片72pt 圆形，锁定态：灰度 + 55% 透明度 + 小锁；点亮态：金箔 `#D4A056` 描边 + 暖光投影
进度环/条徽章详情使用 8px 圆角进度条；坚持系列可用环形进度（参考心情年轮）
Toast / Sheet打卡成功用居中卡片弹窗 300ms；徽章解锁从底部弹出详情 sheet
每日灵感首页顶部胶囊卡片，左侧引号装饰，右侧「引用」按钮
08

动效与关键文案

打卡成功
印章盖下「已打卡」→ 火焰图标 scale 1.2 → 连续天数 +1；音效：纸张轻响（可关）
徽章解锁
灰度滤镜淡出 500ms + 金边描边从 0° 生长到 360° + 弹出详情 sheet；音效：金属轻鸣
补签机制
每月赠送 2 次补签；点击未打卡的过去日期 → 弹出「补签需要写一句话」→ 完成后该日显示橙色补签标记
建议文案
打卡：「今日已打卡 · 连续 N 天」「记下此刻，完成打卡」「补签：给遗漏的一天补一句话」
徽章：「已点亮 X 枚徽章」「继续记录，解锁更多」「分享徽章」「系列：坚持 / 时光 / 心情 / 隐藏」
报告：「X 月手账报告」「本月你最常出现的心情是…」「生成分享卡片」「导出 PDF 手账册」
未来信箱：「把此刻寄给未来的自己」「封存这封信」「还有 X 天开启」
